# Desafio DIO: Criando seu Primeiro Site Completo com HTML

## Sobre o Desafio

Projeto desenvolvido como parte do desafio **Primeiro Site Completo com HTML**.  

Este desafio faz parte das **Formação - HTML Web Developer** da DIO e tem como objetivo criar um site "quase" completo utilizando os principais conceitos estudados no módulo:

- Estruturação e formatação de textos;
- Criação de formulários;
- Uso de mídias e imagens;
- Inserção de tabelas;
- Organização de páginas com menu, cabeçalho e rodapé;
- Navegação entre páginas.

O participante pode escolher uma especialidade médica ou clínica. Neste projeto, foi criada uma clínica fictícia de estética chamada **Nefertiti**, inspirada na elegância do Egito Antigo.

## Páginas do projeto

- **Página inicial:** apresentação da clínica e de seus principais tratamentos;
- **Sobre:** informações sobre a clínica, missão, visão e valores;
- **Horários:** horários de atendimento e tabela de serviços;
- **Contato:** telefones, endereço, mapa incorporado e formulário de contato.

O site segue o padrão solicitado no desafio: todas as páginas possuem menu lateral, cabeçalho com imagem, área de conteúdo e rodapé.

## Tecnologias utilizadas

- **HTML5** para a estrutura e o conteúdo das páginas;
- **CSS3** para o layout, identidade visual e estilização dos componentes;
- Imagens e SVG utilizados como recursos visuais;

## Observação

Este projeto foi criado para fins educacionais como exercício prático do curso da DIO. Os dados de contato, endereço e valores exibidos são fictícios.
